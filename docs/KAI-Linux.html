统一生命周期

所有插件（内核态/用户态）同一状态机

REGISTERED → LOADED → ENABLED → RUNNING
     ↕ 任意状态可热操作
 DISABLED → UNLOADED → (注销)

kai-plugin unplug deepseek   # 热拔出
kai-plugin plug spec.json    # 热插入
kai-plugin enable/disable/reload/start/stop

双态一致性

  • 用户态 — plugin_master.py：事件总线广播、依赖拓扑排序、watchdog 自动重启、A/B 版本
  • 内核态 — ai_plugin_mgr.c：引用计数 + 活跃推理等待，/proc/ai_plugins 热插拔
  • 联动 — 后端下线事件 → 负载均衡器自动摘除 → 熔断器接管
